You are initializing project guidance for this repository. Explore the repo
layout (top-level files, main entry points, config, tests) and then produce a
concise project briefing covering:

1. **What this project is** — one paragraph.
2. **How to build / test / run it** — exact commands.
3. **Code conventions** — language version, linters, file layout, import rules.
4. **Things a new contributor must not break** — contracts, registries,
   permission levels, manual wiring points.

Additional notes from the user: {args}

Write the briefing as a compact markdown document a coding agent can follow.
