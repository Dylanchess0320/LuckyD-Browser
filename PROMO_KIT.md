I got tired of AI browsers that need an account, a subscription, or an API key
before the assistant says a word — so I built one that doesn't.

LuckyD is a Chromium browser (Qt WebEngine) for Windows whose installer sets up
Ollama and a local model automatically. The sidebar assistant then runs 100%
locally: unlimited, offline, private. Zero configuration.

browser tabs, and an agent mode that drives your real, visible tabs. Cloud
providers (Gemini/Groq/DeepSeek/OpenAI/Claude…) are optional BYO-key.

MIT licensed. Happy to answer anything — the AI bridge, the ConPTY-in-a-tab
terminal, and the loopback Browser Control API were the fun parts to build.
