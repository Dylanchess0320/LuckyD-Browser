# GitHub Discussions — Seed Posts (draft)

The repo's GitHub connector can't create discussion posts via API, so these
are drafted here for Dylan to paste in manually once Discussions categories
exist. Written plain and direct.

---

## Category: Show and tell

**Title:** Show what you built with LuckyD

**Body:**

Post what you made with LuckyD — a tab the agent drove for you, a coding
session, a weird automation, whatever. Screenshots or it didn't happen.

I'll feature the best ones.

---

## Category: Q&A

**Title:** Ask anything — setup, models, Windows quirks

**Body:**

Stuck on something? Ask here before opening an issue.

Common ones already answered in docs/FAQ.md: SmartScreen warnings, work PCs
blocking the installer (use the portable ZIP), Cline credits at $0 (it falls
back to free local Ollama), and getting Ollama set up.

If it's a bug, open an issue instead so it doesn't get lost.

## Category: Roadmap ideas

**Title:** What should LuckyD do next?

**Body:**

One idea per reply. Say what it is, who it's for, and why it matters.

No promises — but the stuff with real demand is what gets built. The current
direction is in docs/ROADMAP.md if you want to argue with it.
