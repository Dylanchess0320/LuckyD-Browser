# Configuration Reference

LuckyD is configured via environment variables, `.env` files, and JSON settings.

---

## Key Environment Variables

| Variable | Description |
|---|---|
| `CODING_AGENT_AUTO_APPROVE` | When set to `1`, auto-approves tool execution. |
| `CODING_AGENT_YOLO` | Synonym for auto-approval mode. |
| `LUCKYD_API_PORT` | Port for browser Control API (default `9777`). |
| `HARNESS_URL` | URL for backend agent harness (default `http://127.0.0.1:8000`). |
| `OPENCODE_API_KEY` | API key for OpenCode Zen. |
| `DEEPSEEK_API_KEY` | API key for DeepSeek. |
| `OPENROUTER_API_KEY` | API key for OpenRouter. |
| `GEMINI_API_KEY` | API key for Google Gemini. |
